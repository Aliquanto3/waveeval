# WaveEval

> **Statut : en spécification.** Rien n'est encore utilisable.

Application pédagogique pour apprendre à évaluer l'IA générative, en pratique :

- concevoir un pipeline d'évaluation (métriques, protocole, revue humaine, suivi en continu) ;
- choisir un LLM juge, écrire ses consignes et vérifier qu'il est fiable ;
- construire les jeux de données d'évaluation : golden sets, données synthétiques, annotation ;
- évaluer un RAG et, plus largement, la recherche documentaire par IA (retrieval, génération, bout en bout) ;
- préparer les données et évaluer un fine-tuning de LLM.

Elle sert d'abord à l'autoformation, puis à former des collègues ou des clients, en autonomie ou en atelier.

## Développement

Le projet suit la méthode [BMAD](https://github.com/bmad-code-org/BMAD-METHOD) avec Claude Code, et réduit le coût des agents avec [agent-cost-kit](https://github.com/Aliquanto3/agent-cost-kit).

## English summary

WaveEval is a teaching app, in the specification phase, for learning how to evaluate generative AI: evaluation pipelines, LLM-as-a-judge, evaluation datasets, RAG and AI search evaluation, and data and evaluation for LLM fine-tuning.
